About

LibreAccessibility builds free software with disabled people and their organisations to make technology work better for everyone.

WHY WE EXIST

A lot of accessibility work is done for one client and never shared. We publish ours as open source so others can reuse it.

HOW WE ACCEPT PROJECTS

We take on a project when:

  • It solves a real problem that someone brought to us.
  • It can be open source.
  • Someone will maintain it.

Requests are private.

HOW WE WORK

LibreAccessibility holds the project repositories. Each project has a named maintainer who leads its technical work.

The board oversees project acceptance and decisions to hand over or archive a project. For now, mugiwarafx coordinates this work while the two board seats are open.

If a maintainer steps away, we look for a replacement. Development may pause, and we may archive a project when continuing the work is no longer realistic. Archived public projects keep their code and history available.

This model replaces IATF's former chair and annual community election. Read the transition decision.

LANGUAGE

For now, our website content, repository documentation and official Discord announcements are in English. Everyone is welcome to use the language they feel most comfortable with in conversations, questions and contributions. Translations are on hold, and we may revisit them later.

BOARD OF DIRECTORS

  • mugiwarafx, director
  • Two seats open. See the role.

Directors are not paid.

THIS SITE

We aim for WCAG 2.2 AA. If something on this site doesn't work for you, read how to report a barrier.
