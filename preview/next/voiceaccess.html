Projects / RoboDK VoiceAccess

Programming a robot shouldn't need a mouse.

RoboDK VoiceAccess is voice control for RoboDK, so you can program a robot without a mouse.

What gets in the way?

RoboDK is software for simulating and programming industrial robots.

People who cannot use a mouse need another way to work with robot programming software. VoiceAccess explores voice control for that work.

What are we building?

Voice control for RoboDK, so you can program a robot without a mouse.

The code is open source in the RoboDK VoiceAccess repository. Maintainer: mugiwarafx.

Where does it stand?

Active

The project has an existing code repository. See its documentation and issues for the current implementation and work still to do.
