Current projects

  1. RoboDK VoiceAccess

    Programming a robot shouldn't need a mouse.

    Voice control for RoboDK, so you can program a robot without a mouse.

    Project status
    Active
    Get involved
    Contribute on GitHub or help shape VoiceAccess through discussions on Discord.

  2. Tranandorra website

    An association's website that all its members can use.

    An accessible website for TRANA EM, Andorra's multiple sclerosis association.

    Project status
    Planned
    Get involved
    Help shape the new TRANA EM website. Join the conversation on Discord.

  3. Tranandorra videos

    Exercise videos for people with multiple sclerosis.

    Exercise videos for people with multiple sclerosis, made with TRANA EM. We plan to generate them with AI.

    Project status
    Planned
    Get involved
    Help shape the exercise videos. Share ideas for topics and accessible formats on Discord.
